# Practical Cybersecurity Labs

Documentation of hands-on cybersecurity experiments.

## Lab Environment
- VMware Workstation
- Kali Linux
- Ubuntu Server
- Metasploitable 2
- Windows Server
- Wireshark

## Lab Exercises
1. Network Configuration
2. Network Discovery
3. ARP Analysis
4. ICMP Traffic Analysis
5. TCP Three-Way Handshake
6. Web Application Testing
7. Vulnerability Assessment

## Documentation Format
Each lab will include:
- Objective
- Lab Environment
- Tools Used
- Commands
- Screenshots
- Results
- Lessons Learned
